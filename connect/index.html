Connect to attacompute

Route requests to attacompute's Phala TEE peer through AntSeed Desktop, the direct buyer proxy on port 8377, or the AntSeed Gateway on port 8379.

6c8044f5e6fb2ad70dd31fd7a20fae05a73fa139

Option A: AntSeed Desktop

AntSeed Desktop runs a local gateway at http://127.0.0.1:8379/v1 and manages your wallet and connected tools.

  1. Download and open AntSeed Desktop for macOS, Windows, or Linux.
  2. Open your balance in the top bar and add USDC on Base (or use card checkout where supported). Free models such as minimax-m2.7 work with $0 balance.
  3. Switch the prompt bar to Private to require Phala TEE attestation, then select attacompute (6c8044f5…fa139) as your peer.
  4. Pick any advertised model and start chatting, or open Agents & apps to wire up coding tools automatically.

Option B: Direct buyer CLI (port 8377)

The direct buyer proxy listens on 127.0.0.1:8377 with no API keys required. Point OpenAI-compatible clients at http://localhost:8377/v1 and Anthropic clients at http://localhost:8377.

npm install -g @antseed/cli
antseed buyer start
antseed buyer connection set --peer 6c8044f5e6fb2ad70dd31fd7a20fae05a73fa139
# Optional: print your Base USDC deposit address for paid models (free models need $0)
antseed buyer deposit --no-watch
curl http://localhost:8377/v1/chat/completions \
  -H 'content-type: application/json' \
  -d '{
    "model": "6c8044f5e6fb2ad70dd31fd7a20fae05a73fa139@claude-sonnet-5.5",
    "messages": [
      {"role": "user", "content": "Hello from Texas"}
    ]
  }'

Option C: AntSeed Gateway with API keys & budgets (port 8379)

Need per-app API keys, spend limits, routing policies, or a web console at http://localhost:8379/console? Start the gateway instead — it supervises the buyer automatically.

antseed gateway start
export ANTSEED_API_KEY=$(antseed gateway key create --label "my-app" --json | jq -r .apiKey)

curl http://localhost:8379/v1/chat/completions \
  -H "Authorization: Bearer $ANTSEED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "6c8044f5e6fb2ad70dd31fd7a20fae05a73fa139@minimax-m2.7",
    "messages": [
      {"role": "user", "content": "Hello"}
    ]
  }'
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8379/v1",  # or http://localhost:8377/v1
    api_key="antseed_..."                 # any non-empty string on 8377
)
resp = client.chat.completions.create(
    model="6c8044f5e6fb2ad70dd31fd7a20fae05a73fa139@claude-sonnet-5.5",
    messages=[
        {"role": "user", "content": "Summarize this diff."}
    ]
)
